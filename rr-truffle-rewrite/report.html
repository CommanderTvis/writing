methodology

Benchmarks are driven by org.jetbrains.kotlinx.benchmark on the JMH backend. Mode is avgt; each iteration produces a mean reported in ms/op.

Each benchmark class exposes one or more methods (shown as columns) exercised against a set of samples (shown as rows). Samples come from JMH @Param inputs when present, otherwise collapse to a single synthetic row.
